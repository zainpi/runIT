# runsIT AI Templates launch video

The finished 24.8-second, 1920 × 1080 video is [`brag.mp4`](brag.mp4). Its share thumbnail is [`brag.jpg`](brag.jpg), baked into the MP4's opening frame. [`share-copy.txt`](share-copy.txt) contains a ready-to-use caption.

The editable Hyperframes project is in [`composition/`](composition/). Run `npm run check` there to repeat the validation, or open `http://localhost:3018/#project/composition` while the local preview server is running. [`brag-plan.md`](brag-plan.md) has the storyboard and [`source-notes.md`](source-notes.md) records the researched storefront, dashboard, guide, and optional extras.

Validation: Hyperframes check passed with no runtime, layout, motion, or contrast issues; the lint report has seven structural warnings about the single-file, six-scene composition and no errors. The final MP4 has 744 frames at 30 fps, H.264 video, AAC audio, and a 24.8-second duration. The on-screen PlantLoop project is an illustrative example. The public template pages could not be inspected through the web research tool, so offer details came from the local application source; live checkout and AI provider behavior were not verified.
