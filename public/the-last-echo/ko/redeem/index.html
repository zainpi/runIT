쿠폰 사용

플레이어 ID와 쿠폰 코드를 입력하세요. 보상은 게임 내 우편함으로 지급됩니다. The Last Echo를 열고 받기를 누르세요.

플레이어 ID는 어디에 있나요? The Last Echo에서 설정을 열고 플레이어 ID(# 번호)를 찾으세요. 복사를 누르면 복사됩니다.

보상은 게임 내 우편으로 지급됩니다. 쿠폰으로 재화가 바로 지급되지는 않으며, 항상 게임 안에서 직접 받아야 합니다. 플레이어 ID는 공개 참조 번호이며 비밀번호가 아닙니다. 계정 비밀번호나 로그인 코드는 절대 다른 사람에게 알려 주지 마세요.
