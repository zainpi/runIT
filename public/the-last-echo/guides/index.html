What these guides cover

The Last Echo is still in active development, so these pages describe the current TestFlight demo rather than promising a final feature set. When a balance value or system changes, we update the relevant guide and its date. That makes the handbook useful to players and keeps our public explanations accountable to the game itself.

Found something that no longer matches the demo? Send the screen, game version, and device model to info@runs-it.com. We use those reports to correct both the game and its documentation.
