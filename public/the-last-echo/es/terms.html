7. Recompensas aleatorias («gacha»): publicación de probabilidades

El Juego ofrece mecánicas opcionales de recompensas aleatorias. Nunca es obligatorio comprar para progresar: todo el contenido del juego puede obtenerse jugando con normalidad. La moneda premium que se usa para las tiradas aleatorias también puede ganarse en el juego.

7.1 Tasas de rareza publicadas (por tirada individual)

La probabilidad base de cada nivel de rareza en una tirada estándar de habilidades es:

Rareza Tasa por tirada
Común 62,0 %
Poco común 26,0 %
Raro 9,0 %
Legendario 2,4 %
Mítico 0,5 %
Trascendente 0,09 %
Divino 0,01 %

Las tasas del banner de armas aumentan según el nivel de inversión del banner y siempre se muestran en el juego en cada banner antes de hacer una tirada. Las tasas que se muestran en el juego son las tasas reales y de referencia, y coinciden con estos Términos.

7.2 Sistema de pity (protección garantizada)

  • Pity suave: a partir de la tirada 75 sin un resultado de nivel máximo, la tasa de rareza máxima aumenta un 2 % por tirada.
  • Pity máximo: tienes garantizada una recompensa de nivel máximo (Legendario o superior) como muy tarde en la tirada 100. El contador de pity se muestra en el juego, se guarda y se mantiene aunque cierres la app. Solo se reinicia cuando se activa o cuando obtienes de forma natural un resultado Legendario o superior.

7.3 Garantía del objeto destacado

En un banner destacado, cada resultado Legendario o superior tiene un 50 % de probabilidad de ser el objeto destacado. Si tu primer resultado Legendario o superior en el banner no es el objeto destacado, el siguiente Legendario o superior será con seguridad el destacado. Esta «garantía acumulada» se mantiene incluso después de que termine el banner.

Antes de cada lanzamiento, comprobamos mediante simulación automatizada que las recompensas implementadas coinciden con la tabla publicada. Si un banner concreto muestra reglas diferentes, la información publicada en el juego para ese banner es la fuente de referencia, y esta página se actualizará cuando se adopte el cambio.
